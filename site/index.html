Lambda Cost Watchdog

A serverless AWS cost optimisation tool that identifies unused resources, monitors free-tier usage, and provides monthly cost analysis reports.

View the GitHub repository Read setup instructions

Automated cleanup

Finds stopped EC2 instances, unattached EBS volumes, unused Elastic IPs, and other stale resources.

Free-tier monitoring

Tracks EC2, S3, Lambda, and RDS usage against common AWS free-tier limits.

Cost reporting

Generates cost summaries and estimated monthly savings for review.

Safety first: deploy with DRY_RUN=true and review reports before enabling destructive cleanup actions.
